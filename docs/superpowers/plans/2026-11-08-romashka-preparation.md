# Подготовка Ромашки

Цель: готовый учебный репозиторий для дежурного, не реализация самого агента.
Работа выполняется в существующей ветке hw4; удаление корневого seed_repo.py сохраняется.

Подход: восстановить отсутствующий template/ по API шести исходных приёмочных тестов.
Это совместимая реконструкция, не оригинальный шаблон курса. Альтернатива — ждать оригинал;
она не позволяет завершить запрошенную подготовку сейчас.

- [x] Сначала тесты обычного поведения магазина; проверить, что без shop они не проходят.
- [x] Добавить shop/{catalog,cart,money,delivery,orders}.py и README с ожидаемым поведением.
- [x] Обычные тесты должны проходить; исходные шесть внешних наборов должны выявлять шесть известных багов.
- [x] На временной исправленной копии доказать, что все приёмочные тесты проходят.
- [x] Добавить безопасный экспорт отдельного локального Git-репозитория без эталонов, ключей и acceptance.
- [x] Восстановить исходный seed-скрипт в scripts/, скорректировать базовый путь, не запускать без GitHub-настроек.
- [x] Подготовить рабочую копию ноутбука семинара с исправленным импортом и рабочей директорией.
- [x] Проверить окружение, Docker, документацию и записать оставшиеся внешние шаги.

Проверки: unittest магазина; тесты экспорта (существующая папка не перезаписывается,
нет утечки эталонов); проверка шести багов на исходнике и прохождение после исправлений
только во временной копии. Эталонные замеры курса не выдавать за собственные.

Результат: локальная подготовка завершена; GitHub-публикация отложена до заполнения токена и репозитория.
