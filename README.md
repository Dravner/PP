# ДЗ4. Итоговый агент

Заготовка для выполнения четвёртого домашнего задания. Код решения и результаты замеров пока не добавлены.

## Структура

- `src/main.ipynb` — рабочий ноутбук для решения.
- `материалы/homework04.pdf` — условие задания.
- `материалы/seminar04_solution.ipynb` — исходный пример семинара без изменений.
- `data/issues.json` — учебные задачи и эталоны.
- `data/acceptance/` — приёмочные тесты.
- `data/reference_runs.json` — результаты эталонных прогонов семинара.
- `sandbox/` — Dockerfile и MCP-сервер песочницы.
- `seed_repo.py` — исходный скрипт подготовки учебного GitHub-репозитория.
- `docker-compose.yml`, `.env.example`, `requirements.txt` — исходные настройки и зависимости.
- `results/` — место для результатов собственных прогонов.

## Подготовка окружения

Из корня проекта, после активации выбранного Python-окружения:

```bash
python -m pip install -r requirements.txt
```

Если локального `.env` ещё нет, скопировать `.env.example` в `.env`. Существующий `.env` сохранён: добавить в него недостающие `GITHUB_TOKEN` и `GITHUB_REPO` вручную, сохранить свой `OPENROUTER_API_KEY`. Ключи не коммитить.

Для инфраструктуры примера, после запуска Docker Desktop:

```bash
docker compose --profile build build sandbox
docker compose up -d github-mcp
```

Открыть `src/main.ipynb` и выбрать Python-окружение проекта. Эти команды готовят окружение; запуск итогового агента одной командой нужно реализовать в рамках ДЗ.

## Что учесть в исходных материалах

`seed_repo.py` читает код учебного магазина из `template/`, но этой папки нет в переданных файлах. Перед запуском скрипта потребуется получить шаблон или адаптировать его под собственный учебный репозиторий с тестами. Скрипт изменяет указанный в `GITHUB_REPO` репозиторий.

В ноутбуке семинара есть `import httpx, httpx2`, хотя `httpx2` отсутствует в исходном `requirements.txt`. Перед запуском примера нужно проверить эту зависимость. Его относительные пути (`data/`, `.duty_seed.json`, `pins.json`) рассчитаны на рабочую директорию в корне проекта.

Пример семинара сохранён как справочный материал и не запускался. Эталонные результаты из `data/reference_runs.json` не являются собственными замерами.

## К сдаче

Полные требования находятся в PDF. Потребуются собственный агент, набор задач и скрипт оценки, сравнение минимум трёх конфигураций, обвязка и безопасность, MCP в Docker, запуск одной командой, журналы вызовов, итоговый README и `PITCH.md`.
