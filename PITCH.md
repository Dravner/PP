# Дежурный для «Ромашки»

Агент помогает разработчику магазина разбирать GitHub issues. Он отвечает на вопросы, предлагает исправления багов и создаёт PR после подтверждения человеком.

## Как работает

Issue -> триаж Haiku -> кодер Sonnet в Docker -> проверки кодом -> ревью mini -> человек -> PR. Ответчик читает репозиторий через GitHub MCP. Кодер работает через отдельный MCP-сервер без сети и ключей. Внешняя приёмка запускается после работы кодера и не видна ему.

## Три решения

1. Сравнил команду с одной Sonnet без ревьюера и вариантом целиком на mini. Команда и Sonnet исправили 6 из 6 багов за 43.8 и 45.2 цента на весь набор. Выбрал команду для демонстрации ролей; разница цены слишком мала, чтобы считать её надёжной победой. Mini стоила 3.2 цента, но исправила только 2 бага.
2. Ограничил набор инструментов вместо подключения всех доступных операций. У mini налог GitHub снизился с 2235 токенов для дежурного до 375 для ответчика — на 83%.
3. Сокращаю старые ответы инструментов вместо передачи всей истории. На проверенной истории вход уменьшился с 1936 до 1356 токенов, на 30%. Последние два ответа и связи tool_call_id сохраняются.

## Результат команды

- Качество: триаж 10/10, исправления 6/6, ложных PR нет.
- Цена: 7.3 цента за исправленный баг с учётом расходов на весь набор.
- Время: 22.89 секунды запросов моделей на задачу в среднем; это не полная задержка с Docker и инструментами.

Результаты получены в одном dry-прогоне. Отдельный настоящий PR №11 с исправлением промокода создан с подтверждениями и слит: [PR №11](https://github.com/Dravner/romashka-duty/pull/11).

## Один провал

Mini получила одобрение внутренних проверок на исправление промокода, но внешняя приёмка обнаружила ошибку. Поэтому одного одобрения ревьюера недостаточно: в оценке исправление засчитывается только после независимой приёмки.

## Если будет ещё месяц

Буду сохранять полные трассы и диффы, расширю набор задач, проверю защиту от инструкций внутри issues и измерю полную задержку. Затем повторю сравнение несколько раз, чтобы отделить случайность от устойчивой разницы моделей.
